# DR-001 — Reporte de Defecto

**Título:** El badge del carrito no muestra la cantidad esperada tras agregar un producto

**Severidad:** Media
**Prioridad:** Media

**Pasos para reproducir:**
1. Iniciar sesión con un usuario válido.
2. Agregar un producto al carrito desde el inventario.
3. Verificar el texto del badge del carrito (`shopping_cart_badge`).

**Resultado esperado:** `"2"` *(valor forzado a propósito en el test, cambiando `toHaveText('1')` por `toHaveText('2')`)*

**Resultado obtenido:** `"1"` *(lo que el sitio realmente muestra tras agregar un solo producto)*

**Evidencia:**
- Screenshot: `evidencias/clase07-estado-despues.png` (o el screenshot que generó el fallo)
- Video: generado automáticamente por Playwright en `test-results/<carpeta-del-test>/video.webm`
- Traza: generada automáticamente en `test-results/<carpeta-del-test>/trace.zip`, revisada con `npx playwright show-report` → enlace "Trace"

**Análisis (Error / Defecto / Fallo):**
- **Error:** se modificó intencionalmente el valor esperado en el test (`toHaveText('2')`) para simular una expectativa incorrecta.
- **Defecto:** no existe defecto real en el sistema — la aserción del test fue la que quedó incorrecta.
- **Fallo:** al ejecutar el test, Playwright reportó el fallo porque el valor esperado (`2`) no coincidió con el valor real mostrado por la aplicación (`1`).

**Pasos de verificación / cierre:**
1. Se revirtió el cambio (`toHaveText('1')`).
2. Se volvió a ejecutar la suite y el test pasó correctamente.
3. Se confirma que el "defecto" fue simulado y no corresponde a un problema real del sistema.

**Estado:** Cerrado — defecto simulado, verificado y revertido.
